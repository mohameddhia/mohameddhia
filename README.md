# About Me

Senior Platform Engineer and Software Architect with **7+ years** of experience designing, building, and operating production-grade cloud-native SaaS platforms.

My experience spans the full software delivery lifecycle—from architecture and backend engineering to cloud infrastructure, DevOps, and distributed systems. Throughout my career, I have led the technical delivery of products from **Pre-MVP to production**, building scalable platforms used by enterprise customers across multiple industries.

Currently serving as **Chief Technology Officer at Otraverse**, where I lead the architecture and engineering execution of a multi-tenant immersive commerce platform across backend engineering, cloud infrastructure, DevOps, distributed systems, and platform architecture.

I enjoy building production systems that are scalable, observable, resilient, and designed for long-term maintainability.

## Otraverse — Multi-Tenant Immersive Commerce Platform

> **Chief Technology Officer**

Led the architecture and engineering delivery of a cloud-native multi-tenant B2B SaaS platform from Pre-MVP to production.

### Highlights

- Designed 51 relational PostgreSQL data models
- Delivered 31 production backend modules
- Migrated Express/MongoDB monolith to modular NestJS architecture using the Strangler Fig pattern
- Integrated Stripe, PayPal, and ClickToPay payment gateways
- Designed React ↔ Unity WebGL communication architecture
- Built AWS & GCP infrastructure using Terraform and Ansible
- Implemented CI/CD pipelines with GitHub Actions
- Centralized monitoring using the ELK Stack
